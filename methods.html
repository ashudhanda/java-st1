Methods and Parameter Passing

Method matlab ek kaam ka block jise naam dekar baar-baar bulaya (call) ja sake. Is module me methods banana, parameters, return type, overloading aur pass-by-value samjhenge.

1. Method kya hai?

Method ek statements ka group hai jo ek specific kaam karta hai. Ek baar likho, jitni baar chahe call karo — isse code reuse hota hai aur program saaf rehta hai.

💡
Fayde (advantages)

Code reusability (dobara likhne ki zaroorat nahi), readability, aur easy debugging — galti dhoondhna aasaan.

2. Method ka Syntax

accessModifier returnType methodName(parameters) {
    // method body
    return value;   // agar returnType void nahi hai
}
PartMatlab
Access modifierpublic, private etc. — kaun access kar sakta hai.
Return typeMethod kya wapas dega. Kuch na de to void.
Method nameMethod ka naam (camelCase me likhte hain).
ParametersInput values jo method leta hai (optional).

Example

// do numbers ka sum return karta hai
public static int add(int a, int b) {
    return a + b;
}

// call karna
int result = add(10, 20);   // result = 30

3. Parameters vs Arguments (bahut poochha jaata hai)

TermKya haiKaha
ParameterMethod banate waqt di gayi variables (placeholder)add(int a, int b) — yaha a, b
ArgumentMethod ko call karte waqt di gayi actual valuesadd(10, 20) — yaha 10, 20
💡
Easy trick

Parameter = Place-holder (definition me). Argument = Actual value (call me).

4. return type aur void

  • Agar method koi value wapas deta hai — uska return type likho (int, String...) aur return use karo.
  • Agar kuch wapas nahi deta — return type void hota hai (jaise print karne wala method).
public static void greet() {          // void = kuch return nahi
    System.out.println("Hello!");
}

public static int square(int n) {   // int return karega
    return n * n;
}

5. Method Overloading

Ek hi naam ke multiple methods banana — bas unke parameters alag hone chahiye (number ya type). Isse code padhna aasaan ho jaata hai.

public static int add(int a, int b) { return a + b; }
public static int add(int a, int b, int c) { return a + b + c; }
public static double add(double a, double b) { return a + b; }
⚠️
Yaad rakho

Sirf return type alag hone se overloading nahi hoti — parameters (count ya type) alag hone chahiye.

6. Parameter Passing — Pass by Value

Java me sab kuch pass by value hota hai — matlab method ko value ki ek copy milti hai, original nahi.

a) Primitives ke saath

Original variable par koi asar nahi padta, kyunki sirf copy jaati hai.

static void change(int x) { x = 100; }

int a = 5;
change(a);
System.out.println(a);   // output: 5 (badla nahi)

b) Objects/Arrays ke saath

Yaha value bhi copy hoti hai, lekin wo value ek reference (address) hoti hai. Isliye method us hi object ko change kar sakta hai.

static void change(int[] arr) { arr[0] = 100; }

int[] nums = {5, 6};
change(nums);
System.out.println(nums[0]);   // output: 100 (badal gaya!)
🎯
Exam point

Java hamesha pass-by-value hai. Primitives me actual value ki copy jaati hai; objects/arrays me reference ki copy jaati hai, isliye object ke andar changes reflect hote hain.

✅ Quick Revision

  • Method = naam wala reusable kaam ka block.
  • Syntax: modifier returnType name(params) { ... }
  • Parameter = definition me placeholder; Argument = call me actual value.
  • Kuch return na kare to void.
  • Overloading = same naam, alag parameters.
  • Java = pass by value (objects me reference ki copy).

Practice Questions

Parameter aur argument me difference?
Parameter method ki definition me likhe variables hain (placeholder). Argument wo actual values hain jo call karte waqt pass karte ho.
Method overloading kya hai?
Same naam ke multiple methods jinke parameters (count ya type) alag hote hain. Sirf return type alag hone se overloading nahi hoti.
Java pass-by-value hai ya reference?
Java hamesha pass-by-value hai. Objects/arrays ke case me reference (address) ki copy jaati hai, isliye lagta hai jaise by reference ho.
