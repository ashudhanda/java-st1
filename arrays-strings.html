Arrays & Strings

Array = ek hi type ki bahut saari values ek jagah. String = characters ka group (text). Is module me 1D/2D arrays, traversal aur String ke common methods samjhenge.

1. Array kya hai?

Array ek container hai jo ek hi data type ke multiple values ek saath store karta hai. 100 marks store karne ke liye 100 variable banane ki zaroorat nahi — ek array kaafi hai.

🔑 Key baatein

  • Array ka size fixed hota hai (ek baar set to badalega nahi).
  • Index 0 se shuru hota hai (pehla element = index 0).
  • Same data type ke elements hi rakh sakte ho.

2. One-Dimensional (1D) Array

Declaration & Initialization

// Tarika 1: declare karke new se size do
int[] marks = new int[5];   // 5 elements (sab 0)
marks[0] = 90;
marks[1] = 85;

// Tarika 2: seedha values ke saath
int[] nums = {10, 20, 30, 40};

Traversal — saare elements ghoomna

// normal for loop
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

// for-each loop (aasaan)
for (int n : nums) {
    System.out.println(n);
}
💡
length yaad rakho

Array ka size arrayName.length se milta hai (ye property hai, method nahi — isliye () nahi lagta). String me length() method hota hai — dono me confuse mat karna.

⚠️
Common error

Index range ke bahar jaane par ArrayIndexOutOfBoundsException aata hai. 5 size wale array me valid index sirf 0 se 4 tak hote hain.

3. Two-Dimensional (2D) Array

2D array matlab rows aur columns wala table (matrix). 

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matrix[1][2]);   // row 1, col 2 = 6

// nested loop se traversal
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
}

4. Strings

String characters ka sequence hai (text). Java me String ek class hai (non-primitive), aur ek baar bana hua String immutable (badla nahi ja sakta) hota hai.

String s1 = "Hello";             // literal (recommended)
String s2 = new String("Hello");  // new keyword se
🎯
Exam point — Immutable

String immutable hai — change karne par naya object banta hai, purana wahi rehta hai. Baar-baar change karne ke liye StringBuilder (mutable) use karte hain.

⚠️
== vs .equals() (super important)

== do strings ke reference (address) compare karta hai. .equals() unka actual content compare karta hai. String compare karne ke liye hamesha .equals() use karo.

✅ Quick Revision

  • Array = same type, fixed size, index 0 se shuru.
  • Size = arr.length (no brackets); String me length() (method).
  • 2D array = rows × columns; nested loop se traverse.
  • String immutable hai; badalne ke liye StringBuilder.
  • String content compare karne ke liye .equals(), == nahi.

Practice Questions

arr.length aur str.length() me farak?
Array me length ek property hai (bracket nahi). String me length() ek method hai (bracket lagti hai).
String immutable hone ka matlab?
Ek baar bana String change nahi hota. Change karne par naya object banta hai. Isliye bahut changes ke liye StringBuilder better hai.
Strings compare karne ka sahi tarika?
.equals() use karo — wo content compare karta hai. == sirf reference compare karta hai, jo galat result de sakta hai.
