Classes, Objects, Constructors & this

Ye OOP (Object-Oriented Programming) ki neev hai — aur exam ka sabse important part. Class, object, constructors ke saare types, overloading aur this keyword — sab ekdum detail me.

1. Class — blueprint (naksha)

Class ek blueprint / design hai jisse objects bante hain. Isme do cheezein hoti hain: properties (variables — object ke paas kya hai) aur methods (functions — object kya kar sakta hai). Class khud koi real cheez nahi, sirf design hai.

class Car {
    // properties (instance variables)
    String colour;
    int speed;

    // method (behaviour)
    void chalao() {
        System.out.println("Car chal rahi hai");
    }
}

2. Object — asli cheez

Object class se banai gayi asli (real) cheez hai. Ek class se aap jitne chahe utne objects bana sakte ho. Object new keyword se banta hai.

Car c1 = new Car();   // object banaya
c1.colour = "Red";         // property set ki
c1.speed = 120;
c1.chalao();                // method call kiya
💡
Simple analogy

Class = car ka naksha. Object = us naksha se bani asli car. Ek naksha se kai cars ban sakti hain — meri red car, teri black car (dono alag objects).

⚠️
new kya karta hai?

new keyword heap memory me object ke liye jagah banata hai aur uska constructor call karta hai. c1 us object ka reference (address) pakadta hai.

3. Constructor — (Exam ka favourite ⭐)

Constructor ek special method hai jo object bante hi apne aap (automatically) chal jaata hai — mostly object ki values set (initialize) karne ke liye.

🔑 Constructor ki 3 pakki baatein (yaad rakho)

  • Iska naam class ke naam jaisa exactly same hota hai.
  • Iska koi return type nahi hota (void bhi nahi).
  • Jab bhi new se object banta hai, ye automatic call hota hai.
class Car {
    String colour;

    // Constructor (naam class jaisa, no return type)
    Car(String c) {
        colour = c;
        System.out.println("Nayi car bani: " + colour);
    }
}

Car c1 = new Car("Red");  // constructor apne aap chalega

Constructor ke Types

TypeMatlab
Default constructorBina parameter wala. Agar tum koi constructor na banao, Java khud ek khaali default constructor bana deta hai (jo variables ko default value deta hai: 0, null, false).
Parameterized constructorJisme parameters/values pass karte ho (jaise upar Car("Red")).
Copy constructorEk object ki values dusre naye object me copy karne ke liye.
class Student {
    String name;
    int age;

    Student() {                    // 1. default
        name = "Unknown"; age = 0;
    }
    Student(String n, int a) {    // 2. parameterized
        name = n; age = a;
    }
    Student(Student s) {             // 3. copy constructor
        name = s.name; age = s.age;
    }
}

Constructor Overloading

Ek hi class me multiple constructors banana (alag-alag parameters ke saath) — bilkul method overloading jaisa. Upar wale Student example me teeno constructors overloaded hi hain.

🎯
Exam point — Constructor vs Method

Constructor ka naam class jaisa hota hai + no return type + object bante hi auto-call. Method ka koi bhi naam ho sakta hai + return type hota hai + manually call karna padta hai.

4. this keyword

this ek reference variable hai jo current object ko point karta hai ("ye wala object"). Iske teen main use hain:

a) Instance variable aur parameter ka naam same ho tab

Sabse common use. Jab constructor/method ka parameter aur instance variable ka naam same ho, to this se batate hain ki "class wala" variable kaunsa hai.

class Student {
    String name;
    Student(String name) {
        this.name = name;   // this.name = object ka; name = parameter
    }
}
⚠️
this ke bina kya hota?

Agar this.name = name ki jagah sirf name = name likhte, to Java dono ko parameter hi samajhta aur object ki value set hi nahi hoti (self-assignment). Isliye this zaroori hai.

b) Ek constructor se dusra constructor call karna — this()

Student() {
    this("Unknown", 0);   // parameterized constructor call
}

c) Current object ko return / pass karna

return this; se current object khud wapas kar sakte ho (method chaining me kaam aata hai).

✅ Quick Revision (Module 5 ka nichod)

  • Class = blueprint (design). Object = usse bani real cheez (new se).
  • Constructor = special method, naam class jaisa, no return type, auto-call on object creation.
  • Types: default, parameterized, copy.
  • Constructor overloading = same class, alag parameters wale multiple constructors.
  • this = current object; sabse common use: this.var = var naming clash solve karna.

Practice Questions

Constructor aur method me difference?
Constructor ka naam class jaisa hota hai, koi return type nahi, aur object bante hi auto call hota hai. Method ka koi bhi naam ho sakta hai, return type hota hai, aur ise khud call karna padta hai.
Default constructor kab banta hai?
Jab tum apni class me koi bhi constructor nahi likhte, tab Java automatically ek khaali default constructor bana deta hai jo variables ko default values (0, null, false) deta hai.
this keyword kya hai?
this current object ka reference hai. Iska sabse common use: jab parameter aur instance variable ka naam same ho, tab this.var se object wala variable point karte hain.
Constructor overloading kya hai?
Ek hi class me alag-alag parameters wale multiple constructors banana. Object banate waqt jaise arguments do, waisa hi constructor chal jaata hai.
