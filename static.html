Static Members & Blocks

Last module! static matlab jo cheez object ki nahi, class ki hoti hai — sab objects me common. Static variables, methods aur blocks yaha samjhenge.

1. static ka matlab kya?

Normal (instance) members har object ke apne alag hote hain. Lekin static member class ka hota hai — uski sirf ek hi copy banti hai jo saare objects me share hoti hai.

💡
Simple soch

Instance = har student ka apna roll number (alag-alag). Static = school ka naam (sabhi students ke liye ek hi, common).

2. Static Variable

Class ke saare objects ke beech ek hi copy share hoti hai. Ek object badle to sabke liye badal jaata hai. Object banae bina class ke naam se access kar sakte ho.

class Student {
    String name;              // instance (har object ka apna)
    static String school = "DPS";   // static (sabme common)
}

Student a = new Student();
Student b = new Student();
System.out.println(Student.school);   // class ke naam se: DPS
💡
Use case — counter

Static variable ka classic use: kitne objects bane ye ginna. Har baar constructor me count++ karo — kyunki count sabme common hai, wo total ginta jaayega.

3. Static Method

Static method ko bhi object banae bina class ke naam se call karte hain. main method bhi static hi hota hai (isliye JVM bina object banaye use chala paata hai).

class MathUtil {
    static int square(int n) {
        return n * n;
    }
}

int r = MathUtil.square(5);   // object nahi banaya, direct call → 25
⚠️
Bada rule (exam me aata hai)

Static method ke andar direct instance (non-static) variable ya method use nahi kar sakte, aur na hi this use kar sakte — kyunki static ka koi object hi nahi hota. Static sirf static ko direct access kar sakta hai.

4. Static Block

static { ... } block ek baar chalta hai — jab class memory me load hoti hai, main method se bhi pehle, aur object banane se pehle. Ise static variables ko initialize karne ke liye use karte hain.

class Demo {
    static int x;

    static {                       // static block
        x = 100;
        System.out.println("Static block chala");
    }

    public static void main(String[] args) {
        System.out.println("Main chala, x = " + x);
    }
}
// Output:
// Static block chala
// Main chala, x = 100

✅ Quick Revision (poore syllabus ka last point)

  • static = class ka member, ek hi shared copy, sab objects me common.
  • Access = ClassName.member (object ki zaroorat nahi).
  • Static method me this aur direct instance members allowed nahi.
  • Static block class load hote hi (main se pehle) ek baar chalta hai.
  • main method static hota hai — isiliye JVM bina object ke chalata hai.

Practice Questions

static variable aur instance variable me difference?
Instance variable har object ka alag hota hai. Static variable class ka hota hai — uski ek hi copy sab objects me share hoti hai.
Static method me this kyun use nahi kar sakte?
Kyunki static method class ka hota hai, kisi object ka nahi. this current object ko point karta hai, aur yaha koi object hi nahi hota, isliye allowed nahi.
Static block kab chalta hai?
Jab class memory me load hoti hai — main method aur object creation dono se pehle, aur sirf ek baar. Static variables ko set karne ke liye use hota hai.
main method static kyun hota hai?
Taaki JVM use object banae bina, seedha ClassName.main() ki tarah call kar sake. Agar static na hota to pehle object banana padta, jo shuruaat me possible nahi.
