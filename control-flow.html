I/O, Comments & Control Flow

Is module me input/output lena-dena, comments, decision-making (if/switch) aur loops (for, while, do-while) — sab detail me samjhenge with examples.

1. Output — Screen par cheezein dikhana

Java me output ke liye System.out use hota hai:

MethodKaam
print()Print karta hai, next line par nahi jaata.
println()Print karke next line par chala jaata hai (ln = line).
printf()Formatted output (jaise %d, %s, %f).
System.out.print("Hello ");
System.out.println("World");   // next line
System.out.printf("Age: %d", 20);

2. Input — User se data lena (Scanner)

User se input lene ke liye Scanner class use hoti hai. Pehle ise import karna padta hai.

import java.util.Scanner;

public class Demo {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.print("Naam daalo: ");
    String name = sc.nextLine();
    System.out.print("Age daalo: ");
    int age = sc.nextInt();
    System.out.println("Hi " + name + ", age " + age);
  }
}

nextInt()int number
nextDouble()decimal number
next()ek word (space tak)

⚠️
Famous Scanner bug

nextInt() ke baad nextLine() use karo to wo skip ho jaata hai (kyunki Enter ka \n reh jaata hai). Fix: ek extra sc.nextLine() laga do.

4. Decision Making — if / else

Condition ke hisaab se alag code chalane ke liye. Condition hamesha true/false deti hai.

a) if, if-else, else-if ladder

int marks = 75;
if (marks >= 90) {
    System.out.println("A grade");
} else if (marks >= 60) {
    System.out.println("B grade");
} else {
    System.out.println("Fail");
}

b) Nested if

Ek if ke andar dusra if. Jaise: pehle age check, phir usi ke andar dusri condition.

c) Ternary operator (shortcut)

String res = (marks >= 33) ? "Pass" : "Fail";
// condition ? true_wala : false_wala

5. switch statement

Jab ek hi variable ki bahut saari values check karni ho, tab if-else ki jagah switch saaf-suthra rehta hai.

int day = 3;
switch (day) {
    case 1: System.out.println("Monday"); break;
    case 3: System.out.println("Wednesday"); break;
    default: System.out.println("Other day");
}
🎯
Exam point — break zaroori hai

Har case ke baad break na lagao to fall-through ho jaata hai — matlab agla case bhi chal jaata hai. default tab chalta hai jab koi case match na ho.

6. Loops — kaam baar-baar karna

Loop ek kaam ko bar-bar (repeat) karne ke liye hota hai. Java me 3 main loops hain.

a) for loop

Jab pata ho kitni baar chalana hai. Syntax: for(initialization; condition; update)

for (int i = 1; i <= 5; i++) {
    System.out.println("Number: " + i);
}

b) while loop

Jab pata na ho kitni baar — condition true rahe tab tak chalega. Pehle check, phir chalega (entry-controlled).

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}

c) do-while loop

Pehle ek baar chalega, phir condition check hogi (exit-controlled). Matlab kam se kam ek baar zaroor chalega.

int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
LoopKab use kareinCondition check
forCount pata hoChalne se pehle
whileCount na pata hoChalne se pehle
do-whileKam se kam 1 baar chaleChalne ke baad

break aur continue

  • break — loop ko turant band kar deta hai.
  • continue — current iteration skip karke agli par chala jaata hai.
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;  // 3 skip
    if (i == 5) break;     // 5 par ruk jao
    System.out.println(i);        // output: 1 2 4
}

✅ Quick Revision

  • print vs println — ln next line par jaata hai.
  • Input = Scanner (nextInt, nextLine...). nextInt ke baad nextLine ka bug yaad rakho.
  • switch me break zaroori, warna fall-through.
  • while = pehle check, do-while = pehle chal (min 1 baar).
  • break = loop khatam, continue = ek iteration skip.

Practice Questions

while aur do-while me main difference?
while pehle condition check karta hai, isliye condition false ho to ek baar bhi nahi chalega. do-while pehle body chalata hai, isliye kam se kam ek baar zaroor chalega.
switch me break na lagayein to kya hoga?
Fall-through hoga — matched case ke baad ke saare cases bhi chal jaayenge jab tak break/end na aaye.
break aur continue me farak?
break poora loop band kar deta hai. continue sirf current chakkar (iteration) skip karke agle par jaata hai.
