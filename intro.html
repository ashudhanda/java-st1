Java Basics & Fundamentals

Is module me hum Java kya hai, kaise chalta hai (JDK/JRE/JVM), data types, variables aur operators — sab kuch ekdum basic se samjhenge.

1. Java kya hai? (Introduction)

Java ek high-level, object-oriented programming language hai jo 1995 me Sun Microsystems (James Gosling) ne banayi thi. Aaj ise Oracle maintain karta hai.

Java ki sabse badi khaasiyat hai iska motto:

💡
WORA — "Write Once, Run Anywhere"

Ek baar code likho, aur wo kisi bhi OS (Windows, Mac, Linux) par chal jaayega — bina dobara likhe. Ye Java ki sabse important line hai, exam me aa sakti hai.

Java ke main features (points me yaad rakho)

  • Simple — C/C++ jaisa par aasan (pointers nahi).
  • Object-Oriented — sab kuch class/object ke around.
  • Platform Independent — bytecode kisi bhi JVM par chalta hai.
  • Secure — no direct memory/pointer access.
  • Robust — strong memory management + exception handling.
  • Portable, Multithreaded, Architecture-neutral.

2. JDK, JRE, JVM — (Bahut important)

Ye teen cheezein log confuse karte hain. Ek simple relation yaad rakho:

🔑 Ek line me relation

  • JDK > JRE > JVM (JDK ke andar JRE, JRE ke andar JVM hota hai).
TermFull FormKaam
JVMJava Virtual MachineBytecode (.class) ko run karta hai. Platform independence isi ki wajah se milti hai. Ye ek abstract machine hai.
JREJava Runtime EnvironmentJVM + libraries. Java program chalane ke liye chahiye (run karne ke liye).
JDKJava Development KitJRE + development tools (compiler javac, debugger). Java program banane ke liye chahiye.

Java code kaise chalta hai? (Compilation flow)

Ye flow exam me diagram/steps ke roop me poochha jaata hai:

Source Code (.java)
      | ↓  javac (compiler)
Bytecode (.class)
      | ↓  JVM (interpreter + JIT)
Machine Code → Output
  1. Tum code likhte ho — Hello.java
  2. javac Hello.java → compiler use ko bytecode Hello.class me badalta hai.
  3. java Hello → JVM us bytecode ko machine code me convert karke chalata hai.
🎯
Exam point

Java compiled + interpreted dono hai. Pehle compile hoke bytecode banta hai (compiled), phir JVM use interpret karta hai (interpreted).

Pehla program — Hello World

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
  • public class Hello — class ka naam file ke naam jaisa hona chahiye (Hello.java).
  • main method — program yahin se chalna shuru hota hai (entry point).
  • System.out.println() — screen par output print karta hai.

b) Non-Primitive (Reference) Types

Jaise String, Arrays, Classes, Objects. Ye objects ko refer karte hain, aur inme methods bhi hote hain (jaise String ka .length()).

⚠️
Common confusion

char single quotes me hota hai — 'A'. Aur String double quotes me — "A". Ye galti mat karna.

4. Variables

Variable memory me ek naam wali jagah hai jisme value store hoti hai. Syntax: datatype naam = value;

int age = 20;
double price = 99.5;
char grade = 'A';
String name = "Ashu";
boolean isPass = true;

Variables ke 3 types (scope ke hisaab se)

TypeKaha declare hota hai
Local variableMethod ke andar. Sirf usi method me use hota hai.
Instance variableClass ke andar par method ke bahar. Har object ka apna copy.
Static variableClass ke andar static ke saath. Sabhi objects me common (ek hi copy).

🔑 Variable naming rules

  • Letter, $ ya _ se start ho sakta hai (digit se nahi).
  • Space allowed nahi, keywords (jaise int) use nahi kar sakte.
  • Case-sensitive hai — age aur Age alag hain.

5. Operators

Operators variables/values par operation karte hain. Main types:

a) Arithmetic Operators

OperatorKaamExample (a=10, b=3)
+Adda+b = 13
-Subtracta-b = 7
*Multiplya*b = 30
/Divide (quotient)a/b = 3
%Modulus (remainder)a%b = 1
⚠️
Integer division trap

10 / 3 = 3 (decimal nahi), kyunki dono int hain. Decimal chahiye to ek ko double banao: 10.0 / 3 = 3.33.

b) Relational (Comparison) Operators

== (equal), != (not equal), >, <, >=, <= — result hamesha true/false.

c) Logical Operators

&& (AND), || (OR), ! (NOT) — conditions ko jodne ke liye.

d) Assignment Operators

=, +=, -=, *=, /=, %=. Jaise a += 5 ka matlab a = a + 5.

e) Unary / Increment-Decrement

++ (badhao), -- (ghatao).

🎯
Pre vs Post (favourite exam question)

Pre-increment ++a — pehle badhao, phir use karo.
Post-increment a++ — pehle use karo, phir badhao.
Agar a=5: b=a++ → b=5, a=6. Lekin b=++a → b=6, a=6.

✅ Quick Revision (ek nazar me)

  • Java = platform independent, OOP, WORA.
  • JDK (banane) > JRE (chalane) > JVM (bytecode run).
  • .java → javac → .class (bytecode) → JVM → output.
  • 8 primitive types; String non-primitive hai.
  • Integer division decimal nahi deta; ++a vs a++ yaad rakho.

Practice Questions (khud try karo)

Java platform independent kyun hai?
Kyunki Java code compile hoke bytecode banta hai (machine code nahi). Ye bytecode kisi bhi OS ki JVM par chal jaata hai, isliye WORA.
JDK aur JRE me difference?
JRE sirf program chalane ke liye hai (JVM + libraries). JDK program banane ke liye hai (JRE + compiler jaise development tools).
