## Output prediction (exam favourites)
```java
// Q1: Integer division
System.out.println(7 / 2);        // 3
System.out.println(7 % 2);        // 1

// Q2: String pool
String a = "hi";
String b = new String("hi");
System.out.println(a == b);       // false
System.out.println(a.equals(b));  // true

// Q3: Post increment
int i = 5;
System.out.println(i++ + ++i);    // 5 + 7 = 12

// Q4: char arithmetic
char c = 'A';
System.out.println(c + 1);        // 66 (int ban jata hai)

// Q5: static counter
// Counter ke 3 object banao, count = 3 (shared variable)
```
